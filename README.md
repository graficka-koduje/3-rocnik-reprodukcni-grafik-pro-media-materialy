# 3. ročník – Reprodukční grafik pro média – materiály

Hlavní rozcestník (`index.html`) → 5 tematických rozcestníků (složky) → lekce.

- `maturitni-temata/` – rozcestník 20 maturitních témat z Technologie (podrobně `index.html`, jednoduše `jednoduse/index.html`); každé téma ve složce `tema-NN-nazev/` (`index.html` = podrobně, `jednoduse.html` = jednoduše); letos 2, 4, 5, 7, 11, 15, 20; hotovo: `tema-02-predtiskova-priprava/`
- `polygraficka-montaz-nahledy-natisky/` – odkaz na maturitní téma 2
- `digitalni-workflow/` – lekce `pdf-postscript/` (PostScript a PDF)
- `graficka-uprava-knih/`
- `graficka-uprava-novin-a-casopisu/`
- `publikovani-na-internetu/`

Nová lekce = podsložka v příslušném tématu s vlastním `index.html` + karta v `index.html` tématu.

Maturitní téma: hotový soubor do `maturitni-temata/tema-NN-nazev/`, pak znovu vygenerovat karty v obou rozcestnících maturitních témat (karta se z „připravujeme“ změní na odkaz).
